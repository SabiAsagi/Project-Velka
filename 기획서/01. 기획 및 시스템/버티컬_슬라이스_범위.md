# 버티컬 슬라이스 범위 정의서 (1차 개발 범위)

## 1. 목적

현재 정본은 8개 챕터 맵, 이동용 지하철역, 30명 이상의 NPC, 2개 플레이 모드를 포함한다. 전체를 한 번에 개발하는 것은 리소스 리스크가 크므로, 핵심 재미를 처음부터 끝까지 검증할 수 있는 학교 챕터 1개를 버티컬 슬라이스로 제작한다.

---

## 2. 1차 개발 범위

### 2.1. 맵 (학교 1개)

버티컬 슬라이스는 최신 상세 설계가 완료된 학교 챕터 하나로 제한한다. 프롤로그의 짧은 현실 구간, 세이프 하우스 준비, 학교 구역 진입, 현장 이탈, 거점 복귀까지 하나의 완결된 흐름을 포함한다.

| 맵 | 대표 기믹 유형 | 선정 이유 |
| --- | --- | --- |
| 학교 | 등록/인식형 규칙 (출석부) | 튜토리얼, 진위 판별, 규칙 검증, 캐릭터 전환을 한 번에 검증 가능 |

아파트, 방송국, 병원, 절, 호텔, 놀이공원, 연구소는 후속 개발로 미룬다. 지하철역은 학교 이동 시 정상 운행 컷신만 사용하며, 오염 이벤트는 본편 후반 범위로 보류한다.

### 2.2. 개체 (핵심 조우 3종)

학교의 확정 개체 중 플레이 방식이 겹치지 않는 세 종류를 핵심 조우로 사용한다.

* 세 번째 문장을 읽는 담임(2등급): 소음과 이동 타이밍 학습
* 방송실의 결석생(2등급): 위치 노출과 출석부 등록 규칙
* 보건실의 문진표 작성자(3등급): 자기진술 금지와 이름 작성 금지 규칙

배식대 끝의 급식당번(1등급), 붉은 분필을 든 지각생(1등급), 세 번째 종을 기다리는 수위(2등급)는 짧은 조우와 최종 이탈 조건으로 사용한다.

### 2.3. NPC (핵심 인물만)

| 분류 | 등장 인물 |
| --- | --- |
| 주인공 | 사비 아사기, 카즈네 샤무 |
| 협회 핵심 | 백윤서 (협회장) |
| 부서 대표 (각 1인, 팀장급) | 유가온(정보조사부), 권지혁(전투대응부), 한재윤(기술지원부), 서유림(보호관리부) |

나머지 인물은 이번 단계에서 조직도/텍스트 로그로만 노출하고, 실제 대사·이벤트는 배정하지 않는다.

### 2.4. 시스템 (필수 vs 후순위)

**1차 개발 필수**
* 싱글 모드 캐릭터 전환 시스템
* 탐색/상호작용 시스템
* 규칙서 UI 및 기록 시스템
* 체력/심박수/정신력 시스템 (기본 임계값)
* 세이프 하우스 기본 기능 (회복, 장비 정비, 대화 이벤트)
* 사망/실패 → 재도전 루프
* 학교 챕터의 진입 → 조사 → 규칙 검증 → 현장 이탈 → 거점 복귀 흐름

**후순위 (2차 이후)**
* 온라인 협동 모드
* 성장/해금 시스템의 전체 트리
* 엔딩 분기의 전체 변수 (1차에서는 단일 엔딩 또는 최소 분기로 검증)
* 세이프 하우스의 심화 콘텐츠 (수집품 열람, 잠긴 구역 단서 등)

## 3. 마일스톤 제안

| 단계 | 목표 |
| --- | --- |
| M1 | 학교 회색 상자 맵 + 이동·탐색·캐릭터 전환 가능 |
| M2 | 핵심 개체 3종, 규칙서, 현장 이탈 조건 구현 |
| M3 | 프롤로그·세이프 하우스·학교·거점 복귀를 잇는 버티컬 슬라이스 완주 |
| M4 | 플레이테스트 후 심박수·정신력·개체 대응 수치 1차 조정 |
| M5 | 병원 프로토타입 및 온라인 협동 모드 착수 여부 결정 |

---

## 4. 이 범위 정의의 전제

* 이 문서는 설정을 폐기하는 것이 아니라 개발 순서를 정하는 문서다. 나머지 7개 챕터와 NPC 설정은 유지하되 학교 완주 경험이 검증되기 전에는 본 제작 리소스를 투입하지 않는다.
* M4 단계의 플레이테스트 결과에 따라 밸런스 수치(`밸런스_기획서.md`)와 모드 설계(`게임_모드.md`)를 다시 수정할 수 있다.
