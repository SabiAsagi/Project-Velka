## 2. 세계 구조의 확정 기준

* 현실세계와 괴이세계는 서로 분리되어 있다.
* 현실세계에서 괴이세계로 넘어오는 현상을 **전이**라고 한다.
* 전이는 의도적으로 재현할 수 없으며, 현실세계로 돌아가는 방법도 발견되지 않았다.
* 괴이세계는 학교, 아파트, 방송국, 병원, 절, 호텔, 놀이공원, 연구소 등이 물리적으로 이어진 거대한 폐쇄 공간이다.
* 괴이저항단체, 즉 협회는 괴이세계 내부에서 생존자들이 만든 조직이다.
* 현실의 정부·연구기관과 협회는 동일 조직이 아니다. 현실의 공식 기관은 프롤로그와 프로젝트 벨카의 과거 기록에서 별도 세력으로 다룬다.

## 3. 이동 용어

| 용어 | 의미 |
| --- | --- |
| 전이 | 현실세계에서 괴이세계로 넘어오는 일방향 이동 |
| 구역 진입 | 세이프 하우스에서 학교·병원 같은 챕터 구역으로 이동 |
| 현장 이탈 | 챕터의 탈출 조건을 달성하고 해당 구역을 벗어나는 것 |
| 거점 복귀 | 현장 이탈 후 지하 수로·구형 열차 같은 안전 경로를 통해 세이프 하우스로 돌아오는 것 |
| 현실 귀환 | 괴이세계에서 현실세계로 돌아가는 것. 현재까지 성공 사례 없음 |

게임 내에서 사용하는 `탈출`은 기본적으로 현장 이탈을 뜻한다. 현실 귀환과 혼동될 수 있는 문장에서는 두 표현을 구분해서 쓴다.

## 4. 맵과 개체 기준

확정된 챕터 순서는 다음과 같다.

1. 학교
2. 아파트
3. 방송국
4. 병원
5. 절
6. 호텔
7. 놀이공원
8. 연구소

지하철역은 독립 챕터가 아니라 세이프 하우스와 각 구역을 잇는 이동 전용 공간이다.

현장에서 반복 관찰되는 존재와 현상은 **개체**라고 부른다. **괴이**는 괴이세계의 비정상적인 존재·현상·공간·규칙 전체를 가리키는 상위 개념으로 사용한다.

개체 위험 등급은 1~3등급과 미분류를 사용한다. 기존 4등급은 개체의 상위 등급으로 사용하지 않으며, 구역 전체를 위협하는 사건에는 별도의 **재난급 사건** 태그를 붙인다.

## 5. 플레이어 상태 수치

플레이어가 관리하는 실제 상태 수치는 다음 세 가지다.

* **체력**: 신체 부상과 행동 불능을 나타낸다.
* **심박수**: 추격과 돌발 상황에 대한 단기적인 생리 반응을 BPM으로 표시한다.
* **정신력**: 기억 왜곡, 환각, 규칙 오염에 버티는 장기적인 정신 안정도를 0~100으로 표시한다.

`공포 수치`는 사용하지 않는다. 공포 연출은 심박수와 정신력의 변화, 화면·음향·대사 연출로 표현한다.

## 6. 세이프 하우스의 안전성

세이프 하우스에서는 개체의 직접 출현과 물리적 침입이 억제된다. 그러나 기록 오염, 환청, 기억 변질, 장비 이상 같은 간접적인 괴이 현상까지 완전히 차단되지는 않는다.

## 7. 레거시 문서 처리

`아노말리_설정.md`는 개정 전 아이디어를 보존하는 레거시 자료다. 학교 항목은 `학교_개체.md`로 대체되었으며, 현행 설계에 직접 사용하지 않는다. 병원·호텔 등 아직 새 형식의 상세 문서가 없는 내용은 해당 맵 문서를 작성할 때 참고 자료로만 이관한다.

산속 별장, 오래된 여관, 도심 폐건물은 폐기되었고 장례식장은 절 챕터의 서브 요소로 흡수되었다. 게임 소개나 개발 범위에서는 확정 맵으로 세지 않는다.
