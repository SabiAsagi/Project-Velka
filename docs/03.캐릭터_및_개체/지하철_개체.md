# 지하철 이동 구간 개체 문서

> 지하철역은 독립 챕터가 아니라 세이프 하우스와 각 챕터 구역을 잇는 이동 전용 공간이다.
> 본 문서는 `아노말리_설정.md`의 지하철 설정을 현행 개체·등급 체계에 맞춰 이관한다.

## 1. 구간 역할

초중반에는 협회가 확보한 구형 열차와 승강장이 비교적 안정적인 안전 경로로 기능한다. 후반부에는 프로젝트 벨카의 진상에 가까워질수록 노선과 안내 체계가 오염되어 짧은 돌발 대응 이벤트가 발생한다.

지하철 이벤트는 별도의 규칙서 완성이나 챕터 클리어 조건을 갖지 않는다. 실패하면 즉시 게임 오버가 되는 대신 출발 지점 재시도, 소모품 일부 분실, 심박수 상승, 정신력 감소 중 하나가 적용된다.

## 2. 이동 구간 공통 확인 절차

1. 승강장 번호와 전광판의 열차 번호를 대조한다.
2. 노선도에 목적지가 실제로 표시되어 있는지 확인한다.
3. 사비와 샤무에게 역명이 동일하게 보이는지 비교한다.
4. 열차 내부의 조명과 승객 행동이 정상 범위인지 확인한다.
5. 조건이 하나라도 맞지 않으면 탑승하지 않고 협회에 경로 재확인을 요청한다.

## 3. 확정 개체 및 현상

### 개체명: 막차 안내 방송

**위험 등급**: 2등급  
**분류**: 규칙 강제형 / 기록 간섭형  
**출현 장소**: 승강장, 대합실, 전광판 주변  
**특징**: 마지막 열차 도착을 알리는 방송이 시작되면 역의 조명이 어두워지고 승객 역할을 강요하는 현상이 강해진다. 방송만 믿고 움직이면 잘못된 열차로 유도될 수 있다.  
**대응**: 전광판, 열차 번호, 노선도를 대조한다. 세 정보가 일치하지 않으면 탑승하지 않는다.

### 개체명: 잘못된 열차

**위험 등급**: 3등급  
**특수 태그**: 재난급 공간 강제 이동 위험  
**분류**: 공간 간섭형 / 대체형  
**출현 장소**: 승강장  
**특징**: 정상 열차처럼 보이지만 노선도에 없는 목적지로 향한다. 내부 승객은 모두 같은 자세를 반복하며, 안내 방송은 탑승자의 기억 속 장소를 목적지처럼 읽는다.  
**대응**: 열차 번호와 진행 방향을 확인한다. 내부 조명이 지나치게 어둡거나 승객의 동작이 완전히 같다면 탑승하지 않는다. 문이 닫히기 전 이상을 발견했다면 즉시 하차한다.

### 개체명: 개찰구의 역무원

**위험 등급**: 2등급  
**분류**: 규칙 강제형  
**출현 장소**: 개찰구, 역무실 앞  
**특징**: 승차 기록이 없거나 잘못된 표를 가진 사람을 역무실로 끌고 간다. 끌려간 대상은 다른 사람의 시야와 기록에서 점차 지워진다.  
**대응**: 개찰구를 통과하기 전에 표와 카드의 출발역·목적지를 확인한다. 개찰구가 저절로 열려 있어도 기록 확인 없이 지나가지 않는다.

### 현상명: 노선도에 없는 역

**분류**: 미분류 현상  
**출현 장소**: 노선도, 전광판, 열차 내부 안내판  
**특징**: 존재하지 않는 역명이 사람마다 다르게 보인다. 고향, 잃어버린 사람, 현실로 통하는 출구처럼 보일 수 있다.  
**대응**: 처음 보는 역명을 목적지로 선택하지 않는다. 사비와 샤무, 협회 관제 담당에게 보이는 명칭을 서로 비교한다.

## 4. 개발 범위

버티컬 슬라이스에서는 세이프 하우스에서 학교로 이동하는 짧은 정상 운행 컷신만 사용한다. 위 개체와 오염 이벤트는 본편 후반부용으로 보류하되, 전광판 글자가 한순간 바뀌는 정도의 복선은 배치할 수 있다.
