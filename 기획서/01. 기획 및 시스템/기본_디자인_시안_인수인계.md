## 타이틀 화면 (v0.29.0)

v0.28.0 에서는 아래 원본 인수인계의 "타이틀 화면은 건드리지 않는다"를 "게임의 기존 타이틀을 그대로 둔다"로 잘못 읽어 옛 타이틀을 남겼다.
뜻은 반대다. 피그마에서 완성한 타이틀 디자인을 재해석하거나 고치지 말고 그대로 게임에 옮긴다.
v0.29.0 에서 로고 · 배경 · 배치 · 글꼴 · 메뉴 스타일 · 움직임을 시안 기준으로 다시 만들었다.

  - 불러오기(이어하기 아래), 종료(맨 아래).
  - 오른쪽 아래 작은 버전 표기 — 버전 규칙상 타이틀에 버전이 보여야 한다.

# Project Velka UI 인수인계

## 프로젝트
- 미스터리 호러 게임 "Project Velka"의 UI. React 19 + Vite + Tailwind CSS v4
- 기획·자산 원본: https://github.com/SabiAsagi/Project-Velka.git
- 폰트(public/assets/fonts): Pretendard(본문), 나눔명조(제목·대사), 나눔고딕코딩(장비·코드 표기)
- 캐릭터 기능색: 사비 아사기 #45A1B5, 카즈네 샤무 #D9A336
  - 공용 UI에는 쓰지 않는다. 사비 전용 기기(해킹 단말)는 예외

## 파일
- src/App.tsx — 타이틀, 탐색 HUD(챕터1), 조사 수첩(Tab), 기록소, 설정, 제작진
- src/Hack.tsx — 해킹 단말 + 미니게임 3종(회로 연결 / 암호 대조 / 영상 프레임 복원)
- src/index.css — 전체 스타일. 맨 끝 "통합 테마" 블록이 최신 디자인 방향

## 디자인 방향 (타이틀 화면은 건드리지 않는다)
> 게임 반영 메모: "건드리지 않는다" = 완성된 피그마 타이틀을 고치지 말고 그대로 옮긴다 (위 "타이틀 화면 (v0.29.0)").
- B. 현장 장비(바탕): 어두운 금속 패널, 얇은 선, 상태 표시등, 나눔고딕코딩 라벨
  - 선택 상태는 회백색. 붉은색(--blood)은 위험 신호에만
- A. 협회 기록물(문서): 조사 수첩 안쪽 종이, 기록소 규칙 카드(바랜 종이, 검열 줄, 분류 도장)
- C. 오염(규칙 위반 시에만)
  - 위반 순간: .field-screen.contam-burst (1.4초 붉은 주사선 + 흔들림)
  - 누적 위반 수: .contam-1 ~ .contam-3 (HUD 번짐 → 화면 일렁임)
  - 위반 조항: .paper-rule.is-violated (잉크 번짐)
  - prefers-reduced-motion이면 애니메이션 끔

## 해킹 단말 (중요)
- 해킹은 사비 본인의 휴대 해킹 단말(S.ASAGI · FIELD RIG MK-II)로 한다. 학교 기기와 무관
- 바깥 기기 프레임은 퍼즐 종류와 상관없이 항상 사비 단말 하나(.sabi-device)
- 퍼즐 영역 안쪽만 원격 대상 느낌: 회로=녹색 기판, 암호=호박색 터미널, 영상=흑백 CCTV
- 샤무는 해킹 불가: "이런 건 사비 담당이야. 사비로 바꾸자."

## 조사 수첩
- 탭: 목표·확인 / 맵 규칙서 / 협회 보고서(MJ-01) / 수집 기록
- 요원별 손글씨 메모가 규칙 조항 바로 아래에 붙는다
  (사비·샤무·권지혁·백윤서·서유림·유가온·한재윤·협회 공용, 각기 다른 필체)

## 작업 규칙
- 작은따옴표가 들어간 문자열은 큰따옴표로
- 컴포넌트는 default export
- 확인 명령: pnpm exec tsc --noEmit
- 이모지 사용 금지

## 현재 상태
- A+B+C 조합을 타이틀 외 전체에 1차 적용 (타입 검사 통과, 화면 확인 전)
- 버그 수정 완료 (브라우저로 화면 확인함)
  - Esc: 창(조사 기록·해킹·현장 선택지)이 열려 있으면 그 창만 닫힌다. 아무 창도 없을 때만 타이틀로
  - 해킹: 결과 창에서 Esc를 눌러도 해제·경보 결과가 기록된다. 암호 퍼즐은 튜토리얼·결과 창이 떠 있는 동안 입력을 받지 않는다. 회로가 처음부터 풀린 채로 시작하지 않는다
  - 종이(.paper) 배경이 안 나오던 문제, 규칙서 탭에서 수첩 창이 아래로 밀리던 문제
  - 현장 상단 바의 조사 기록·뒤로 버튼이 캐릭터 카드에 가려지던 문제, 규칙 미리보기 상태 표시 줄바꿈
  - 기록소 규칙이 종이 카드로 보이도록 (CSS가 .rule-card를 가리키고 있었음 → .report-row)
  - 화면 등장 애니메이션·구역 필터·오염 3단계 필터가 화면에 남아 창이 밀리던 문제 (필터는 안쪽 요소에 건다)
  - 알림(toast)이 아래쪽 클릭을 막던 문제
