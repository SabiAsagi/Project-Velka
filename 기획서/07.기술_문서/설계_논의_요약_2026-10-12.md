# 프로젝트 벨카 설계 논의 요약 (2026-10-07 ~ 10-12)

> Claude와 진행한 설계 논의를 다른 AI나 협업자에게 넘기기 위해 정리한 문서다.
> **[확정]** 은 작가가 승인해 기획서에 반영된 내용, **[제안]** 은 논의 중이며 아직 승인되지 않은 내용이다.
> 상세 내용은 각 항목에 적힌 기획서 파일이 정본이다.

---

## 0. 프로젝트 개요

* **프로젝트 벨카**: Godot 4.7(GDScript) 기반 2.5D 쿼터뷰 미스터리 호러.
* 주인공 사비 아사기(분석·잠입)와 카즈네 샤무(돌파·보호)를 전환하며 플레이한다.
* 괴이와 싸우지 않고, **규칙서**를 읽고 의심하고 검증해 살아남는 나폴리탄(규칙 괴담) 구조다.
* 괴이세계는 학교·아파트·방송국·병원·절·호텔·놀이공원·연구소가 이어진 폐쇄 공간이며, 생존자 조직 **괴이저항단체(협회)** 의 본부(세이프 하우스)를 거점으로 구역을 조사한다.
* 기획서 폴더: `기획서/01~07` 번호 폴더. 게임 코드: `scripts/`, `scenes/`, `data/`.

## 4. 규칙 검증 기믹 공통 틀 [확정]

`06.챕터1_학교/학교_규칙_검증_기믹.md`

* **세계는 진실대로, 수첩은 믿음대로**: 규칙의 진짜 진위는 데이터에 고정, 수첩의 진위 태그는 플레이어의 판정. HUD 경고는 판정을 따른다(오염으로 판정하면 경고 안 함).
* 흐름: 발견(미확인) → 근거 1개(추정) → 근거 전부 → 수첩에서 판정 → 확정.
* 경로: **사비** = 안전한 분석(스파이 비전·문서 대조·흔적), **샤무** = 위험 검증(규칙을 직접 시험해 근거를 한 번에 채우지만 위반 처리). **금지 등급은 샤무도 시험 불가.**
* 오판정: 그 차이로 위반이 일어나면 추정으로 하락, 위반이 근거로 추가, 협회 서식의 사고 기록이 수첩에 남음.
* 학교 규칙별 적용(4장)은 규칙서 개정 후 작성.

## 5. 학교 챕터(무진고등학교) 전면 개정

`06.챕터1_학교/학교_챕터_구조.md` — 기존 개체 6종과 생존자용 규칙서는 **전부 새로 쓴다**(맵 구조는 유지).
작성 순서: **① 개체 확정 → ② 학교 안전수칙(생존자용 규칙서) → ③ 협회 보고서**.

### 5-1. 핵심 법칙 [확정]
* 학교는 시간표대로 돌아가며 들어온 사람을 **학생으로 등록**하려 한다. 규칙 위반마다 출석 도장, 다 차면 학생으로 확정(실패).
* 플레이어는 **조퇴**로 나간다(전학·다른 학교 서류는 쓰지 않음). 조퇴증 칸을 채워 종례 전에 정문을 통과한다.
* 진짜 이름은 내주지 않고, 조회 때 받은 **'전학생 ○번'** 으로 지낸다.
* 문체: **친절한 안내문체**. 수칙서에는 이전 생존자들의 손글씨가 덧쓰여 있다(맞는 것·틀린 것 혼재 → 검증 근거).
* 개체는 장소마다 **정해진 상주 개체**(무작위 아님). 학교는 단순하게, 후반 챕터로 갈수록 복잡하게. 단발 현상 3~4개 별도.

### 5-2. 두 개의 실패 축 [확정]
| | 등록 (출석 도장) | 의심 (외부인 티) |
| --- | --- | --- |
| 학교의 시선 | 우리 학생으로 만들자 | 우리 학교 사람이 아니다 |
| 끝 | 학생으로 정리됨(흡수) | 외부인으로 처리됨(배제) |

* 딜레마: 학생처럼 굴면 의심은 줄지만 등록이 진행된다. 조퇴증은 그 사이의 좁은 길.
* 잔혹함은 **학교 일과의 모양**을 한다(출석·벌·준비물·교복·급식·청소·분리수거).
* 위반 등급별 대가: 안전=살이 파인 **출석 도장**(누적) / 주의=**벌 서기**(팔 고정) / 위험=**준비물 수거**(치아·손톱·손가락) / 금지=**강제 진급**(교시가 넘어가고 공책엔 자기 피로 쓴 필기).
* 부가 상황: 사비·샤무 다른 반 배정(서랍에서 동료의 '분실물'), 계단 층 증가(게시판의 '우수 작품'), 조퇴증 칸 지워짐, 상담실 호출(기억 상실·혀에 출석번호), 거울 속 교복.
* 등록 완료: 교복이 피부에 꿰매지고 번호가 박음질되어 책상에 접혀 앉혀짐 → 군중 '학생들' 중 하나. 이후 탐사에서 발견될 수 있음.
* 외부인 발각 3단계: 수군거림 → 신고("얘 우리 학교 애 아니에요") → 발각 방송·전교 봉쇄·외부인 지도. 대피 장소에서 다음 종까지 버티면 해제.
* **외부인 처리는 훨씬 더 잔혹하게, 잡힌 장소의 쓰임새를 따른다.** 화면엔 끌려가는 장면과 통신 두절까지만, 이후는 보고서가 발견물로 알린다.
  * 급식실 → 조리실로 끌려감 → 이후 수거한 급식 일부가 실종 대원으로 확인
  * 교실 → '실습 시간' → 과학실 표본 / 보건실 → '치료' → 약품장의 이름 없는 병
  * 복도·계단 → 청소 시간 분리수거 → 소각장 옆 수거함 / 정문 → 수위가 '내보냄' → 담장 콘크리트 속 위치 신호

### 5-3. 협회 보고서 작성 방식 [확정]
* 탐사 기록 서식: `○차 탐사 — OOO 대원이 ~하다가 ~됨. 통신 두절.` → `이후 ○차 탐사에서 ~를 수거.` → `조사 결과 실종된 OOO 대원으로 확인. 공식 사망 처리.` (생환·실종 유지 등도 구분)
* 협회가 알아낸 무진고의 규칙(수칙서에 없는 원인·조건·예외), 기밀 사항, 대원들의 각주·잡담·팀장 제지 코멘트 포함.
* 화면에서 보여주지 않은 잔혹한 결과는 보고서가 맡는다.

### 5-4. 조퇴 절차와 개체 [제안 — 작가 확인 대기]
| 칸 | 장소·시간 | 개체 | 내용 |
| --- | --- | --- | --- |
| ① 학년·반·번호 | 교실·아침 조회 | **담임**(집행자, 출석·순회) | '전학생 ○번' 가짜 신분 |
| ② 조퇴 사유 | 급식실·점심 | **영양사 선생님** (작가 제안) | 급식을 먹고 탈이 나야 '급식 후 이상 증세' 확인. 무엇을 먹은 것인지는 보고서가 알려줌 |
| ③ 보건 확인 | 보건실·5교시 | 보건 선생님 (건강검진형 또는 단순 확인형 중 미정) | 증상 확인·보건 일지 기록 |
| ④ 보호자 연락처 | 교무실·청소 시간 | 교무실 청소 당번 (제안) | 비상연락망에서 '전학생 ○번'의 보호자 번호를 알아냄 |
| ⑤ 담임 승인 | 교실·종례 | 담임 | 그 번호로 보호자에게 전화 → 틀리면 "그런 애 없는데요" → 발각 |
| 제출 | 정문 | **수위** | 칸이 비거나 틀리면 문이 열리지 않음 |

* 군중: **학생들**(대부분 개체, 진짜 생존자가 섞임, 정상 체크리스트로 판별).
* 학교 직인 칸은 실제 조퇴증에 없으므로 제외.

### 5-5. 미결 사항
1. 위 조퇴 절차(①~⑤) 확정 여부
2. 보건실 개체 형태(건강검진 보건 선생님 / 단순 확인형)
3. 청소 시간 개체를 교무실 청소 당번으로 할지
4. 단발 현상 3~4개 내용
5. 실패 문구(등록 실패 / 외부인 처리) — 예: "내일도 꼭 등교하세요!" / "분리수거는 꼭 지켜 주세요!"
6. 등록 완료된 대원을 군중 속에서 이름으로 구출할 수 있는지
7. 이후 단계: 개체 상세(외형·규칙·준비물·장소별 처리) → 학교 안전수칙 → 협회 보고서 → `학교_규칙_검증_기믹.md` 4장 → 데이터(`data/rules/school_rules.json`) 반영
