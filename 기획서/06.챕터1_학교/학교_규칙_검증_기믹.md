# 학교 규칙 검증 기믹

> 본 문서는 학교 챕터에서 플레이어가 규칙서의 규칙을 검증해 수첩에 **조사 진행**과 **진위 태그**를 채워 나가는 방식을 정의한다.
> 규칙 상태 3축(조사 진행 · 진위 태그 · 위반 결과)의 정의는 `공식_설정.md` 6장을 따른다.
> 1~3장과 5장은 규칙 내용과 무관한 **공통 틀**이다. 4장의 학교 규칙별 적용은 학교 규칙서 개정 후 작성한다.

---

## 1. 기본 원리: 세계는 진실대로, 수첩은 믿음대로

* 각 규칙이 실제로 어떻게 작동하는지(**진짜 진위**)는 데이터에 고정되어 있다. 게임 세계와 개체는 플레이어의 판정과 상관없이 항상 이 진실대로 반응한다.
* 수첩에 기록되는 진위 태그는 **플레이어가 그 규칙을 그렇게 믿는다**는 기록이다. 게임은 판정 순간에 정답 여부를 알려주지 않는다.
* HUD 경고는 플레이어의 판정을 따른다.
  * `정상`으로 판정한 규칙: 해당 구역에 들어가면 평소처럼 경고한다.
  * `조건부`로 판정한 규칙: 경고에 "조건에 따라 달라질 수 있음"을 덧붙인다.
  * `오염`으로 판정한 규칙: 경고하지 않는다.
* 따라서 판정이 틀리면 HUD가 잘못 안내하고 플레이어도 잘못 행동하게 된다. 별도의 벌점 없이, 잘못된 믿음 자체가 대가를 만든다.

---

## 2. 진행 흐름

```
발견(수첩 기록) → 미확인
근거 1개 확보   → 추정
근거 전부 확보  → 수첩에서 "판정하기" 가능 → 정상 / 조건부 / 오염 중 선택 → 확정
```

* 규칙서를 읽거나 조사로 처음 접하면 수첩에 기록되고 조사 진행은 `미확인`이다.
* 근거를 하나라도 얻으면 `추정`이 된다.
* 규칙에 필요한 근거(`evidence_required`)를 모두 모으면 수첩에서 판정할 수 있다. 판정하면 `확정`이 되고, 플레이어가 고른 진위 태그가 붙는다.
* 근거가 모자란 상태에서는 판정할 수 없다. 대신 사비가 무엇이 더 필요한지 짧게 언급한다.

### 2-1. 근거를 얻는 경로

사비와 샤무 모두 규칙을 확정까지 끌고 갈 수 있지만, 길과 비용이 다르다.

| 경로 | 방법 | 얻는 근거 | 비용 |
| --- | --- | --- | --- |
| **사비 (분석)** | 스파이 비전 흔적 감지, 다른 문서와 대조, 현장 흔적 조사 | 근거 1개씩 | 안전하지만 느리다 (스파이 비전 쿨타임, 이동, 시간) |
| **샤무 (위험 검증)** | 규칙을 일부러 시험한다 | 남은 근거를 한 번에 모두 | 해당 규칙의 위반으로 처리된다 (위반 결과 등급에 따른 체력·심박수·정신력·소음) |
| **실수로 위반** | 모르고 어기거나 잘못 믿고 어긴다 | 근거 1개 | 위반 결과 등급에 따른 대가 |

* 샤무의 위험 검증은 위반 결과 등급이 `위험` 이하인 규칙에만 쓸 수 있다.
* **`금지` 등급 규칙은 샤무도 시험할 수 없다.** 시도하면 샤무가 스스로 멈추고 짧게 반응한다(예: "이건… 해보면 안 되는 거지?"). 금지 등급의 무게를 플레이어에게 가르치는 장면으로 사용한다.
* `판정 보류` 등급 규칙은 결과를 모르는 상태이므로 샤무의 위험 검증 대상에서 기본적으로 제외한다. 예외가 필요하면 규칙별로 `shamu_test`에서 허용한다.

### 2-2. 근거의 종류

| 종류 | 예시 | 주 담당 |
| --- | --- | --- |
| 스파이 비전 | 평소엔 보이지 않는 흔적, 잉크·분필의 차이, 개체의 반응 직전 징후 | 사비 |
| 문서 대조 | 같은 규칙서의 다른 조항, 다른 위치의 사본, 낡은 원본, 생존자 메모 | 사비 |
| 현장 흔적 | 이전 조사의 흔적, 사고 현장, 남겨진 물건 | 사비·샤무 |
| 목격 | 다른 존재가 규칙을 어기거나 지켰을 때의 결과를 직접 봄 | 사비·샤무 |
| 위반 | 직접 어겨서 결과를 겪음 | 샤무(의도) / 누구나(실수) |

## 3. 판정이 틀렸을 때

* 수첩의 진위 태그가 진짜 진위와 다른 상태에서, 그 차이 때문에 위반이 일어나면 판정이 틀렸다는 사실이 드러난다.
  * 예: 진짜로는 정상인 규칙을 `오염`으로 판정해 무시하다가 어긴 경우, 진짜로는 오염인 조항을 `정상`으로 믿고 따르다가 원래 규칙을 어긴 경우, `조건부` 규칙의 조건을 놓친 경우.
* 판정이 틀렸다는 것이 드러나면:
  * 조사 진행이 `추정`으로 내려가고 진위 태그가 지워진다.
  * 이번 위반이 근거 1개로 추가된다. 다시 판정하려면 근거를 다시 모아야 한다.
  * 사비(또는 조작 중인 캐릭터)의 짧은 반응 대사가 나온다.
  * 수첩에 협회 보고서 서식의 **사고 기록**이 남는다. 형식은 `괴이저항단체_학교보고서.md`의 사고 기록과 같게 맞춘다.

```
2026.xx.xx / 현장 기록 - 본관 1층 방송실 앞
판정: [확정·정상] → 실제와 다름
경위: 손글씨 조항을 따라 방송 호출에 대답함. 직후 ……
```

* 판정이 맞았는지는 위반이 일어나기 전까지 드러나지 않는다. 맞는 판정은 아무 일도 일어나지 않는 것으로 증명된다.

## 4. 학교 규칙별 적용

> 학교 생존자용 규칙서 개정 후 작성한다.

규칙마다 아래 항목을 정한다.

| 항목 | 내용 |
| --- | --- |
| 진짜 진위 | 정상 / 조건부 / 오염 |
| 위반 결과 등급 | 안전 / 주의 / 위험 / 금지 / 판정 보류 |
| 사비 경로 근거 | 안전하게 얻을 수 있는 근거 1~2개와 얻는 방법 |
| 샤무 경로 | 위험 검증 가능 여부와, 시험했을 때 일어나는 일 |
| 오염 조항이면 | 어떤 원래 조항을 어떻게 변조했는지 |

학교는 오염 1단계 구간이므로(`공식_설정.md` 7-1) 오염 조항은 아주 적게 두고, 판별 단서는 뚜렷하게 둔다. 튜토리얼에서는 정상·조건부·오염을 각각 한 번씩 경험하게 하는 것을 목표로 한다.

## 5. 데이터 구조 (구현 기준)

규칙 데이터(`data/rules/*.json`)의 각 규칙에 아래 필드를 추가한다.

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `true_veracity` | `NORMAL` / `CONDITIONAL` / `CORRUPTED` | 진짜 진위. 게임 세계의 반응 기준이며 플레이어에게 직접 노출하지 않는다 |
| `evidence` | 배열 | 근거 목록. 각 항목은 `id`, `label`(수첩 표시 문구), `source`(`spy_vision` / `compare` / `inspect` / `witness` / `violation`) |
| `evidence_required` | 정수 | 판정에 필요한 근거 수. 학교 기본값 2 |
| `shamu_test` | 객체 | `allowed`(샤무 위험 검증 가능 여부), `line`(시험 불가 시 반응 대사) |
| `corrupts` | 규칙 ID | 오염 조항일 때, 변조된 원래 조항 |

* 플레이어의 판정은 기존 필드 `progress`, `veracity`에 저장한다. `veracity`는 플레이어의 믿음이고 `true_veracity`는 진실이다.
* 확보한 근거는 규칙별 `evidence_found`(근거 `id` 배열)로 저장해 세이브와 체크포인트에 포함한다.

### 5-1. 조정 가능한 값

| 값 | 기본 | 비고 |
| --- | --- | --- |
| 학교 `evidence_required` | 2 | 후반 챕터는 3 이상으로 늘려 오염 판별을 어렵게 한다 |
| 샤무 위험 검증 허용 등급 | 위험 이하 | 금지는 항상 불가 |
| 판정 오류 시 조사 진행 | 추정으로 하락 | |
