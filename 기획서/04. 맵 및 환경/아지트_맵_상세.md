# 사비·샤무 아지트 맵 상세 (프롤로그)

> 프롤로그 P-02(첫 번째 실종 의뢰)와 P-03(사라지는 의뢰인들)의 무대.
> 시나리오 정본: `기획서/05.스토리/게임 시나리오/01.프롤로그 게임 시나리오.docx`
> 생성기: `tools/level_gen/hideout/hideout_gen.py` → `scenes/prologue/HideoutWorld.tscn`, `scenes/chapters/Prologue_Hideout.tscn`

---

## 1. 개요

도시 외곽 공업사 뒷길에 있는 낡은 2층 건물. 간판을 떼어 낸 폐업 정비소를 사비와 샤무가 빌려
1층은 차고·장비실, 2층은 사무실 겸 집으로 쓴다. 의뢰를 받고, 조사하고, 먹고 자는 곳이 한 건물에 있다.

## 2. 플레이어 경험 (Player Fantasy)

- "둘이서 꾸려 온 생활"이 보이는 공간. 사비의 모니터와 조사 보드, 샤무의 정리된 장비 벽이 한 집 안에서 대비된다.
- 현실세계 파트의 따뜻한 조명과 생활 소음 → 이후 괴이세계(차가운 조명, 소리 없음)와 대비되는 기준점.
- 조사 보드에 실종자 사진이 늘어나는 장면으로 불안이 생활 공간 안으로 스며든다.

## 3. 구조 (Detailed Rules)

건물 평면 14 m(동서, x) × 10 m(남북, z), 층 높이 3.8 m. 남쪽이 골목(정면)이고, 카메라는 북쪽 위에서 남쪽을 내려다본다.
그래서 화면에 보여야 하는 벽 장식(조사 보드, 장비 벽, 작업대)은 카메라 쪽을 향하는 남쪽·서쪽 벽에 둔다.

### 1층 — 차고·장비실 (y = 0)

| 구역 | 위치 (x, z) | 내용 |
|---|---|---|
| 셔터 | 남쪽 벽 x 0.8~6.2 | 내려진 차고 셔터 (열리지 않음) |
| 출입문 | 남쪽 벽 x 10.6~11.6 | 골목으로 나가는 철문 (프롤로그 동안 잠김) |
| 차 | x 1~5.6, z 1~6 | 샤무가 모는 낡은 승합차 |
| 장비 벽 | 서쪽 벽 z 6.6~10 | 타공판 장비 걸이, 철제 사물함, 장비 가방 (P-03 끝 '샤무가 장비 가방을 꺼낸다') |
| 선반·타이어 | 북쪽 벽 x 1.2~5.2 | 낮은 철제 선반, 쌓인 타이어 |
| 운동 공간 | x 6.8~11, z 3.4~7.4 | 매트, 샌드백, 벤치, 덤벨 |
| 작업대 | 남쪽 벽 x 6.6~10.2 (셔터와 철문 사이) | 공구 걸이, 바이스, 부품 상자 |
| 철계단 | 동쪽 벽 x 12.6~13.8, z 8.6→2.6 | 북쪽 발치에서 남쪽으로 오르는 1줄 계단 (2층 남동쪽 참으로 도착) |

### 2층 — 사무실 겸 집 (y = 3.8)

| 구역 | 위치 (x, z) | 내용 |
|---|---|---|
| 계단 참 | x 11.4~14, z 0~2.6 | 계단 구멍(z 2.6~8.6) 둘레 난간 |
| 욕실 | x 0~2.6, z 0~2.6 | 벽으로 막힌 작은 욕실 (세면대·변기·샤워 칸) |
| 사비 작업 공간 | 서쪽 벽 x 0~1.2, z 3~6.6 | 모니터 6대 ㄱ자 책상, 서버 랙, 의자 |
| 조사 보드 | 남쪽 벽 x 2.8~5.7 (욕실 옆) | 코르크 보드 + 실종자 사진·붉은 실, 아래 자료 테이블 (P-03 분석 구간) |
| 응접 공간 | x 3~8, z 2.6~6 | 낮은 테이블과 마주 보는 소파 2개 (P-02 의뢰인 컷신) |
| 주방·식탁 | x 7.6~11.8, z 0~3.6 | 남쪽 벽 조리대·싱크·냉장고, 2인 식탁 |
| 샤무 침실 | x 5.6~8.9, z 6.6~10 | 칸막이 벽 + 커튼 입구, 침대·옷걸이 |
| 사비 침실 | x 8.9~12.4, z 6.6~10 | 칸막이 벽 + 커튼 입구, 침대·책 더미 |
| 창 | 남쪽 벽 x 5.9~7.4·8.2~10.2, 서쪽 벽 z 7.4~9 | 블라인드를 내린 창 (안이 들여다보이지 않게) |

### 조사할 수 있는 것 (초기 구현)

| 대상 | 내용 |
|---|---|
| 조사 보드 | 실종자 사진과 메모. P-03 분석 구간의 진입점 |
| 사비의 모니터 | 해킹 패드와 연결된 작업 화면 |
| 응접 테이블 | 의뢰인이 두고 간 실종자 사진 |
| 장비 벽 | 샤무의 장비 가방 |

### 이야기 진행 (P-02 → P-03)

`scripts/chapters/PrologueHideout.gd`가 순서대로 진행한다. 진행 상황은 스토리 플래그 `prologue_*`에 남는다.

| 단계 | 내용 | 끝나는 조건 |
|---|---|---|
| 1. 의뢰인 | 2층 응접 공간에서 시작. 동쪽 소파의 의뢰인(얼굴 없는 실루엣)과 대화 (`prologue_p02_client`) | 대화가 끝나면 의뢰인이 사라짐 |
| 2. 사진 | 응접 테이블 사진 조사 → 화면 노이즈 → `prologue_p02_photo` | 대화 종료 |
| 3. 몽타주 | 검은 화면 자막 6줄 (사라지는 의뢰인들). E/Enter로 넘김 | 자막 종료 |
| 4. 조사 보드 | 사비로 조사 보드 조사 → 사건 보드 화면 (`data/puzzles/prologue_board.json`). 증거 카드 12장(핵심 8 + 헷갈리게 하는 증거 4: 명함·막차 시간표·택배 송장·가족사진). 카드를 펼치면 밑줄 친 키워드(번호·시각·장소)를 눌러 붉게 표시할 수 있고, 다른 증거에 같은 단서가 표시돼 있으면 알아챈다. 증거마다 사비의 손글씨 메모가 붙는다. 살펴본 카드끼리 붉은 실로 이어 연결 5개를 찾는다(틀리면 왜 상관없는지 떠오른다). 막히면 '생각 정리'(H): 누를수록 구체적인 혼잣말 힌트(분류 → 증거 하나 → 두 증거). 플레이어가 곧 사비이므로 보드의 문장은 모두 사비 자신의 혼잣말·메모로 쓴다. 다 찾으면 지도에 핀(산업단지 북측 3구역). 샤무로는 열리지 않음 | 공통 좌표 확인 → `prologue_p03_talk` |
| 5. 장비 가방 | 샤무로 1층 장비 가방 조사 → `prologue_p03_bag`. 사비로는 진행되지 않음 | 대화 종료 |
| 6. 끝 | 자막 "다음: 폐쇄 공장", `prologue_hideout_done` | — |

분석 화면: 틀린 답은 사비의 힌트만 나오고 벌점은 없다. ESC로 닫으면 진행은 유지된다.

## 4. 수치 (Formulas)

- 층 높이 3.8 m (학교 맵과 같은 값 — `WorldPhaseController.LEVEL_HEIGHT`).
- 계단: 높이 3.8 m / 길이 6.0 m (경사 약 32°, 캐릭터 floor_max_angle 42° 이내), 폭 1.2 m (캐릭터 캡슐 지름 0.8 m + 여유).
- 통로 최소 폭 1.0 m (캡슐 지름 0.8 m + 0.2 m).

## 5. 예외 상황 (Edge Cases)

- 1층에 있을 때 2층은 카메라에서 숨긴다 (school_level 레이어 방식 재사용).
- 셔터·출입문은 프롤로그 동안 열리지 않는다 (밖은 아직 만들지 않음).
- 계단 구멍 둘레는 난간 충돌로 막아 떨어지지 않게 한다.
- 계단 난간 충돌판은 아래쪽 0.8 m를 잘라 둔다. 계단 발치에 옆(서쪽)에서 들어올 때 판 끝에 걸리지 않게 하기 위해서다.

## 6. 연결 (Dependencies)

- 학교 맵 생성기 부품 재사용: `emit.SceneWriter`, `batch.Batch`, `palette`(재질·셰이더), `props_base.Props`, `stairs2.flight`.
- 씬 구성: `PlayerParty`, `FollowCamera`, `PrototypeHUD`, `DialogueBox`, `PauseMenu`(오토로드).
- 이후: P-02 컷신 대사, P-03 분석 퍼즐, 폐쇄 공장(P-04)으로의 이동.

## 7. 조정값 (Tuning Knobs)

- 건물 크기, 구역 사각형, 계단 위치는 생성기 상단 상수로 둔다.
- 조명 색·세기 (현실세계 따뜻한 3000K 계열).

## 8. 완료 조건 (Acceptance Criteria)

- 1층 출입구 쪽에서 출발해 철계단으로 2층에 오를 수 있다.
- 2층의 모든 구역(욕실, 작업 공간, 응접, 주방, 침실 2개)에 걸어서 들어갈 수 있다.
- 조사 대상 4개를 조사하면 설명 대사가 나온다.
- 생성기 검사: 면 겹침 없음, 가구 충돌 겹침 없음.
- 자동 검사: `tests/smoke/hideout_smoke_test.gd` (맵 동선), `tests/smoke/prologue_hideout_story_smoke_test.gd` (이야기 진행)
