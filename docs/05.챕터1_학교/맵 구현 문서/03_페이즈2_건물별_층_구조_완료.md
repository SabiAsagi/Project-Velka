## 1. 구현 원칙

- 평면도 형상과 위치를 최우선으로 사용했다.
- 본관은 이미지 위쪽을 북쪽으로 유지했다.
- 별관은 이미지 오른쪽이 실제 북쪽, 이미지 아래가 실제 동쪽이 되도록 전체 배치 조립 단계에서 `Y +90°`를 적용했다.
- 강당은 이미지 아래가 실제 북쪽, 이미지 위가 실제 남쪽 무대가 되도록 전체 배치 조립 단계에서 남북축만 변환하고 동·서는 바꾸지 않았다.
- 각 층은 별도 정적 씬으로 만들었고 전체 맵 자동 생성 스크립트를 사용하지 않았다.
- 공통 외곽과 정확히 반복되는 본관 2~4층 북측 행만 재사용 컴포넌트로 분리했다.
- 가구·소품·최종 재질·조명·NPC·내비게이션은 추가하지 않았다.
