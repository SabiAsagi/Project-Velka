## 3. 확정한 방향과 좌표

- 전체 배치와 본관: 이미지 위가 실제 북쪽이다.
- 별관: 이미지 왼쪽이 실제 남쪽, 오른쪽이 실제 북쪽, 아래 긴 외벽이 실제 동측 운동장 방향이다.
- 강당: 이미지 아래가 북측 주출입구, 이미지 위가 남측 무대이며 동·서는 바꾸지 않는다.
- 월드 원점은 운동장 중심 `(0, 0, 0)`이다.
- 본관 중앙 현관과 조회대 중심선은 `X=0`에 맞춘다.

## 4. 확정한 핵심 구조

- 전체 부지: 약 `190m × 140m`
- 운동장: 약 `70m × 45m`
- 본관: 약 `60m × 18.5m`, 지하 1층·지상 4층·옥상
- 별관: 지상 3층
- 강당: 약 `40m × 26m`, 지상 2층
- 공통 층간 높이: `3.8m`
- 본관 1F 대지 높이: `Y=3.8`
- 별관 1F·운동장·강당 1F: `Y=0`
- 본관 2F와 별관 3F 구름다리 바닥: `Y=7.6`
- 본관 계단 코어 3개, 별관 계단 코어 2개
- 엘리베이터: 본관 1기, 별관 1기, 강당 없음
- 본관 일반교실 18개, 자습실 3개, 동아리실 6개
- 본관 4F 자습실 개인 칸막이 24석
- 별관 1F 급식실 504석
- 강당 2F는 ㄷ자 관람석과 중앙 개방부
- 본관 옥상은 중앙 계단만 연결하며 엘리베이터는 연결하지 않는다.
- 스탠드 중앙은 조회대와 하부 창고이며 계단은 양끝에만 둔다.

## 5. 충돌 처리

최종 `00_전체_배치.png`의 실제 크기는 `1472 × 1320`, SHA-256은 `39a33a062579ff9978de0dcbf7ab0a42a207daf0bfbaaf9d48620606f2a49523`이다.

구현 가이드 표의 `1600 × 1290`과 다르지만 사용자가 현재 로컬 파일을 최종본으로 직접 확정했으므로 실제 PNG를 정본으로 채택했다. 별관 방위, 스탠드 중앙 구조, 본관 4F 자습실 좌석 수, 본관 측면 보행로, 월드 원점과 관련된 이전 차이는 개정 가이드와 최종 PNG를 적용해 해결했다.
