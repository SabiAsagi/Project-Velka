> 본 문서는 map_info.md에서 확정된 8개 챕터 맵 중 1번 챕터 "학교"의 건축/구조/기믹 설계 문서다.

> **중요:** 기존 anomaly_info.md의 "5-1. 폐교 괴이"와 구 map_info.md의 "폐교 맵" 섹션은 방치된 폐교 이미지를 전제로 작성되었으나, 본 챕터는 **정상적으로 수업이 진행 중인 것처럼 보이는 학교**로 컨셉이 변경되었다.

## 1. 맵 컨셉

학교 맵은 프로젝트 벨카의 첫 챕터이자 튜토리얼 성격을 가진다.

핵심 공포는 "아무도 없는 곳에 혼자 있다"가 아니라, **"사람이 이렇게 많은데, 그중 누구도 진짜라고 확신할 수 없다"** 는 감각이다.

플레이어(사비, 샤무)가 진입하는 학교는 겉보기에 완전히 정상적으로 돌아가고 있다.
학생들은 교실에 앉아 있고, 교사는 수업을 하고, 종이 울리면 쉬는 시간이 되고, 복도에는 학생들이 오간다.

이 "완전히 정상적임"이 오히려 가장 큰 위협이다. 시간이 지나면서 다음과 같은 균열이 하나씩 드러난다.

* 같은 학생이 다른 교실에도 앉아 있다.
* 어제와 오늘의 급식 메뉴, 시간표, 방송 멘트가 토씨 하나 다르지 않다.
* 일부 학생/교사는 눈을 깜빡이지 않거나, 같은 동작을 반복한다.
* 출석부에 있어야 할 이름이 없거나, 없어야 할 플레이어의 이름이 이미 적혀 있다.
* 창밖 운동장 풍경이 시간이 지나도 조금도 바뀌지 않는다.

학교 맵의 튜토리얼적 기능은 "위협을 피하는 법"뿐 아니라, **"이 공간에서는 익숙하고 정상적인 것도 의심해야 한다"** 는 게임 전체의 기본 태도를 학습시키는 것이다.

## 2. 맵 규모 및 구조

### 2-1. 규모 개요

| 항목 | 설정 |
| --- | --- |
| 학교 종류 | 종합 고등학교 (지상 4층 + 지하 1층 본관, 2층 별관) |
| 학년 구성 | 1~3학년, 학년당 6개 학급 |
| 학급 규모 | 학급당 정원 약 28명, 전교생 약 500명 규모 |
| 부속 건물 | 별관(특별교실동), 체육관(강당), 운동장 |
| 접근 통로 | 정문, 후문 (2-5 참고) |

전교생 500명 규모라는 설정은 "학교가 가득 차 있다"는 인상을 주기 위한 기준선이며, 실제 게임 내에서는 이 중 일부(주요 동선에 등장하는 인원)만 실제로 랜더링되고 나머지는 소리, 그림자, 방송 등으로 존재감만 암시된다.

### 2-2. 건물 구성

* **본관**: 지상 4층 + 지하 1층. 정문, 교무실, 대부분의 교실, 방송실이 위치.
* **별관 (특별교실동)**: 지상 2층. 본관 3층과 구름다리(연결 통로)로 이어짐. 과학실, 미술실, 음악실, 컴퓨터실 위치.
* **체육관 (강당)**: 별도 단층 건물. 조회, 행사, 체육 수업에 사용.
* **운동장**: 본관과 체육관 사이의 공터. 조회대 위치.

### 2-3. 본관 층별 구성

| 층 | 주요 구역 |
| --- | --- |
| 지하 1층 | 창고, 보일러실, 구 방공호(현재는 봉쇄 표시) |
| 1층 | 정문 현관, 교무실, 행정실, 보건실, 급식실, 학생회실 |
| 2층 | 1학년 교실 (1-1 ~ 1-6), 1학년부장실 |
| 3층 | 2학년 교실 (2-1 ~ 2-6), 별관 연결 구름다리, **복도 끝의 "존재하지 않는 교실"** |
| 4층 | 3학년 교실 (3-1 ~ 3-6), 방송실, 자습실 |
| 옥상 | 옥상정원, 급수탑, 평소 잠겨 있는 옥상 출입문 |

### 2-4. 별관 층별 구성

| 층 | 주요 구역 |
| --- | --- |
| 1층 | 과학실, 미술실 |
| 2층 | 음악실, 컴퓨터실 |

### 2-5. 접근 통로

* **정문**: 등하교 시 사용하는 정식 출입구. 최종 탈출 구역과 연결된다.
* **후문**: 운동장 반대편에 위치. 평소엔 잠겨 있으며, 탈출 조건을 만족하지 못한 상태로 열려는 경우 다른 구역(변질 구역)으로 이어진다.

### 2-6. 변질 구역 후보지

건축적으로 "있어서는 안 되는" 위치들로, 맵 후반부 변질 구역으로 활용된다.

* 3층 복도 끝의 존재하지 않는 교실 (설계도상 벽이어야 할 자리)
* 지하 1층 구 방공호 (원래는 봉쇄되어 출입 기록조차 없어야 함)
* 옥상 출입문 안쪽 (평소 잠겨 있어 아무도 들어간 적 없어야 함)

## 3. 맵 공통 구조 적용

### 3-1. 진입 구역 — 정문 / 등굣길

현실의 일상적인 등굣길과 거의 동일하다. 다만 다음과 같은 미세한 위화감이 배치된다.

* 휴대폰 신호가 약해지거나 끊긴다.
* 교문 앞 안내판의 날짜가 이상하게 표기되어 있다(요일과 날짜가 맞지 않음 등).
* 등교하는 학생들의 수가 항상 일정하다 — 아무리 시간이 지나도 늘거나 줄지 않는다.

이 구역에서는 아직 직접적 위협이 없다. 플레이어가 "여기 뭔가 이상하다"는 감을 잡기 시작하는 단계다.

### 3-2. 조사 구역 — 1층(교무실·보건실·급식실) / 2·3층 교실

본격적으로 단서를 수집하는 구역. 수업이 진행 중인 여러 교실을 지나며, 출석부·시간표·학생 명단을 비교하게 된다.

이 구역의 핵심은 "정상 vs 이상 체크리스트"를 플레이어 스스로 채워나가는 것이다. (4장 참고)

### 3-3. 위험 구역 — 4층 교실 / 방송실 / 종소리 직후의 복도

종이 울리는 시점, 방송이 나오는 시점을 기점으로 개체 활동이 본격화된다.

### 3-4. 변질 구역 — 3층 복도 끝 교실 / 지하 방공호 / 옥상 출입문 안쪽

2-6에서 정의한 후보지가 실제로 활성화되는 구역. 현실적인 건축 구조가 무너지는 지점.

### 3-5. 탈출 구역 — 정문 / 방송실 최종 제어

정문으로 보이는 곳이 항상 출구인 것은 아니다. 최종적으로는 출석부의 오류를 바로잡고, 자신의 이름이 "학생"으로 완전히 고정되기 전에 벗어나야 한다.

## 4. 핵심 신규 기믹 — "진짜 학생 판별"

학교 맵의 튜토리얼 전용 핵심 기믹이다. 정상적으로 보이는 학교 안에서, 어떤 존재가 실제 사람(다른 실종자/생존자)이고 어떤 존재가 개체인지 구분해야 한다.

### 판별 단서

| 단서 | 설명 |
| --- | --- |
| 반복 동작 | 같은 학생이 정확히 같은 타이밍에 같은 동작(연필 돌리기, 뒤돌아보기 등)을 반복 |
| 그림자 없음 / 어긋난 그림자 | 창문 빛 아래에서 그림자가 없거나 위치가 어긋남 |
| 대사 loop | 말을 걸면 토씨 하나 다르지 않은 동일한 대답만 반복 |
| 명단 중복 | 같은 이름의 학생이 서로 다른 반 출석부에 동시에 존재 |
| 무반응 | 종이 울리거나 큰 소리가 나도 전혀 반응하지 않음 |

### 사비 활용

사비의 스파이 비전은 이 판별 기믹의 핵심 도구다. 그림자 어긋남·무반응 단서는 스파이 비전을 켰을 때 육안보다 뚜렷하게 강조되어 보인다.

### 싱글 모드 재현

샤무 조작 중에는 판별 단서를 인지하기 어렵고, 사비로 전환해야 정확히 판별할 수 있다 — game_mode_info.md의 "전환 필수 게이트" 방식 재현.

### 실패 시

판별에 실패해 잘못된 대상과 접촉하면, 해당 개체가 즉각 활성화되어 위협으로 전환된다. (구체적 개체 반응은 school_entity.md 참고)

## 6. 협동 기믹

### 싱글 모드 (전환 기반)

* 사비로 여러 교실의 출석부를 대조해 이상한 이름/중복 이름을 찾는다.
* 샤무로 전환해 복도의 위협 개체 주의를 끌어 시간을 벌고, 다시 사비로 전환해 방송실에 잠입한다.

### 협동 모드 (실시간, 향후 확장)

* 한 플레이어(사비)가 교실 안에서 출석부를 확인하는 동안, 다른 플레이어(샤무)는 복도에서 위협 개체의 이동 패턴을 감시하며 무전으로 타이밍을 알려준다.
* 같은 교실을 봐도 한쪽 화면에는 정원이 다 찬 것으로, 다른 쪽 화면에는 한 자리가 빈 것으로 보이는 시야 차이 연출.

## 7. 탈출 조건

최종 탈출 조건은 다음 두 가지를 모두 만족해야 한다.

1. 여러 교실에서 수집한 출석부 정보를 대조해, 실제로 존재하지 않는(개체가 만들어낸) 학생 이름을 특정한다.
2. 방송실에서 해당 이름을 출석부와 방송 명단에서 지우고, 자신의 이름이 완전히 "학생"으로 고정되기 전에 정문을 통과한다.

정문을 통과할 때 운동장이 정상적으로 보이는지가 성공/실패의 시각적 신호로 사용된다.

## 8. 세계관 연결 단서 배치 (예시)

* 교무실 캐비닛 안, "2000년 2월 8일"이 언급된 오래된 학적부 조각.
* 방송실 안, 프로젝트 벨카 관련 문구가 섞인 낡은 녹음 테이프.
* 3층 복도 끝 교실(변질 구역)에서 발견되는, 사비/샤무와 이름이 비슷한 옛 실종 학생 기록.

이 단서들은 학교 챕터 자체의 진실보다는, 후속 챕터(특히 연구소)에서 회수되는 떡밥으로 기능한다.
