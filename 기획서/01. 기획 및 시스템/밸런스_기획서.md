# 밸런스 수치 설계 시트 (초안 프레임워크)

> 본 문서는 실제 최종 수치가 아니라, 밸런싱 논의를 시작하기 위한 뼈대와 플레이스홀더 값이다. 프로토타입 테스트 이후 반드시 조정된다.

## 1. 체력 / 심박수 / 정신력 기본값

| 항목 | 사비 아사기 | 카즈네 샤무 | 비고 |
| --- | --- | --- | --- |
| 기본 체력 | 100 | 120 | 샤무가 물리적으로 더 튼튼한 설정 반영 |
| 안정 시 심박수 | 78 BPM | 68 BPM | 캐릭터별 기본값, 플레이테스트 후 조정 |
| 심박수 상승 배율 | 기본치 x1.3 | 기본치 x0.8 | 사비는 생리 반응이 빠르고 샤무는 평소 안정적 |
| 기본 정신력 | 100 | 100 | 0 도달 시 정신 붕괴 |
| 정신력 감소 배율 | 기본치 x0.85 | 기본치 x1.0 | 사비는 심박이 빨라도 판단을 오래 유지함 |
| 유대감 링크 발동 조건 | 상대 체력 30 이하 또는 정신력 30 이하 | 좌동 | 상대 상태가 자신의 심박수와 정신력에 영향 |

`공포 수치`는 별도 수치로 사용하지 않는다. 순간적인 압박은 심박수, 장기적인 정신 오염은 정신력으로 처리한다.

## 2. 심박수 단계

| 구간 | 상태 | 효과 |
| --- | --- | --- |
| 60~99 BPM | 안정 | 페널티 없음, 은신 시 호흡 소리가 작음 |
| 100~129 BPM | 경계 | 호흡음 증가, 심박 UI와 음향 강조 |
| 130~159 BPM | 고조 | 시야가 약간 좁아지고 정밀 상호작용 속도 -10% |
| 160 BPM 이상 | 위험 | 시야 왜곡, 이동속도 -15%, 은신 중 호흡 노출 위험 증가 |

심박수만으로 즉시 사망하거나 무작위 오조작이 발생하지는 않는다. 안전한 장소에서 움직임을 줄이면 자연스럽게 내려가며, 추격·부상·동료 위험·규칙 위반 시 빠르게 상승한다.

## 3. 정신력 단계

| 구간 | 상태 | 효과 |
| --- | --- | --- |
| 71~100 | 안정 | 정보 왜곡 없음 |
| 41~70 | 불안정 | 약한 환청, 기록 글자 흔들림, 가짜 단서의 시각적 간섭 증가 |
| 1~40 | 오염 | 강한 환각, 잘못된 방향 신호, 분석 힌트 감소, 동료 확인 행동 필요 |
| 0 | 정신 붕괴 | 행동 불능 또는 현장 실패. 체크포인트에서 재시도 |

정신력은 현장에서 자동으로 크게 회복되지 않는다. 동료와의 확인 대화, 제한된 안정제, 안전 구역의 짧은 휴식으로 일부 회복하고 세이프 하우스에서 본격적으로 치료한다.

## 4. 자원 소모 기준값 (아이템_설정.md 연동)

| 아이템 | 효과량 | 최대 소지 수량(기본 난이도) | 비고 |
| --- | --- | --- | --- |
| 구급상자 | 체력 50% 회복 | 2 | |
| 진통제 | 체력 15% 회복 + 붉은 노이즈 감소 | 3 | |
| 신경 안정제 | 심박수 -25 BPM(최저 60), 정신력 +15 | 2 | 연속 사용 제한 |
| 손전등 배터리 | 손전등 지속시간 +5분 | 4 | 배터리 총 소모 속도는 맵별로 다르게 설정 |
| 조명탄 | 개체 시선 분산 20초 | 2 | 두 캐릭터 사용 가능, 샤무는 투척 준비가 빠름 |

> 난이도별로 최대 소지 수량 및 드랍률을 -30%(고난이도) ~ +30%(쉬움) 범위에서 조정.

## 5. 챕터 난이도 곡선 (개체 등급 기준 배치 가이드)

| 챕터 순서 | 주 등급 | 부 등급 | 미분류 등급 등장 |
| --- | --- | --- | --- |
| 1 (튜토리얼 성격) | 1~2등급 위주 | 최대 1개의 3등급 | 없음 |
| 2~3 | 2등급 위주 | 3등급 1~2개, 재난급 사건 복선 | 1개 |
| 4~6 | 2~3등급 혼합 | 재난급 사건 발생 가능 | 1~2개 |
| 후반 | 3등급 포함 복합 배치 | 재난급 사건 직접 대응 | 다수 |

`재난급 사건`은 개체의 4등급이 아니라 구역 붕괴, 대규모 전이, 안전 경로 상실 같은 광역 사건 태그다.

## 6. 협동 모드 vs 싱글 모드 난이도 보정

| 항목 | 싱글 모드 | 협동 모드 |
| --- | --- | --- |
| 괴이 감지 범위 | 기준치 | 기준치 x1.2 |
| 추격 지속시간 | 기준치 | 기준치 x1.15 |
| 전체 자원 드랍량 | 기준치 | 기준치 x1.6 (2인이 나눠 사용) |
| 캐릭터별 최대 소지량 | 기준치 | 기준치 |
| 진행 필수 아이템 | 조작 캐릭터 기준 공용 | 두 플레이어에게 즉시 공유 |

| 원인 | 즉시형/누적형/지연형 | 비고 |
| --- | --- | --- |
| 개체 포획 | 즉시형 | |
| 체력 소진 | 즉시형 | |

| 규칙 위반 - 안전/주의 등급 | 누적형 | 3회 누적 시 페널티 발동 |

## 8. 다음 단계

이 시트는 프로토타입 빌드에서 실제 플레이테스트를 거쳐 아래 항목을 검증해야 한다.

1. 챕터 1 클리어까지 걸리는 평균 시간과 사망 횟수
2. 심박수 단계와 정신력 감소량이 실제로 "불편하지만 진행 가능한" 수준인지
3. 협동 모드 밸런스 보정치가 실제 2인 플레이에서 체감상 적절한지
