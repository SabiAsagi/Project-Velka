# 버티컬 슬라이스 범위 정의서 (1차 개발 범위)

## 1. 목적

현재 설정 문서는 13개 맵, 30명 이상의 NPC, 2개 플레이 모드를 포함하는 방대한 스코프를 갖고 있다. 전체를 한 번에 개발하는 것은 리소스 리스크가 크므로, 핵심 재미를 검증할 수 있는 최소 단위(버티컬 슬라이스)를 먼저 정의한다.

---

## 2. 1차 개발 범위

### 2.1. 맵 (3개로 제한)

이미 상세 설계가 되어 있는 맵 중, 서로 다른 종류의 기믹을 대표할 수 있는 3개를 선정한다.

| 맵 | 대표 기믹 유형 | 선정 이유 |
| --- | --- | --- |
| 폐교 | 등록/인식형 규칙 (출석부) | 초반 튜토리얼 성격에 가장 적합, 규칙이 비교적 명확 |
| 병원 | 신분 전환형 규칙 (환자/의료진) | 중반 난이도, 신분 위장 메커니즘 검증 |
| 호텔 | 반복 구조형 규칙 (객실/층수) | 분리형 협동 구간 검증에 적합 |

나머지 10개 맵(아파트, 지하철역, 산속 별장, 놀이공원, 방송국, 장례식장, 연구소, 종교시설, 여관, 도심 폐건물)은 로드맵으로 미루고, 이번 단계에서는 설정만 유지한다.

### 2.2. 괴이 (맵당 3~4종)

각 맵에서 이미 상세 설계된 괴이 중, 등급이 다른 것을 섞어 배치한다.

* 폐교: 출석을 부르는 목소리(2등급), 복도 감독관(3등급), 빈 책상의 학생(2등급)
* 병원: 순번 간호사(3등급), 404호 환자(4등급, 회피 전용), 호출벨의 손(2등급)
* 호텔: 프런트 관리자(2등급), 객실의 투숙객(3등급), 체크아웃을 막는 벨보이(3등급)

### 2.3. NPC (핵심 인물만)

| 분류 | 등장 인물 |
| --- | --- |
| 주인공 | 사비 아사기, 카즈네 샤무 |
| 협회 핵심 | 백윤서 (협회장) |
| 부서 대표 (각 1인, 팀장급) | 유가온(정보조사부), 권지혁(전투대응부), 한재윤(기술지원부), 서유림(보호관리부) |

나머지 인물은 이번 단계에서 조직도/텍스트 로그로만 노출하고, 실제 대사·이벤트는 배정하지 않는다.

### 2.4. 시스템 (필수 vs 후순위)

**1차 개발 필수**
* 싱글 모드 캐릭터 전환 시스템
* 탐색/상호작용 시스템
* 규칙서 UI 및 기록 시스템
* 심박수/공포 수치 시스템 (기본 임계값)
* 세이프 하우스 기본 기능 (회복, 장비 정비, 대화 이벤트)
* 사망/실패 → 재도전 루프

**후순위 (2차 이후)**
* 온라인 협동 모드
* 성장/해금 시스템의 전체 트리
* 엔딩 분기의 전체 변수 (1차에서는 단일 엔딩 또는 최소 분기로 검증)
* 세이프 하우스의 심화 콘텐츠 (수집품 열람, 잠긴 구역 단서 등)

## 3. 마일스톤 제안

| 단계 | 목표 |
| --- | --- |
| M1 | 폐교 챕터 플레이 가능 (싱글 모드, 핵심 루프 1회 완주) |
| M2 | 병원 챕터 추가 + 세이프 하우스 왕복 루프 완성 |
| M3 | 호텔 챕터 추가 (분리형 협동 기믹의 싱글 모드 버전 검증) |
| M4 | 3개 챕터 통합 플레이테스트 → 밸런스 수치 1차 조정 |
| M5 | 온라인 협동 모드 프로토타입 착수 여부 결정 |

---

## 4. 이 범위 정의의 전제

* 이 문서는 "설정을 줄이자"는 것이 아니라 "개발 순서를 정하자"는 것이다. 나머지 10개 맵과 NPC 설정은 그대로 유지하되, 실제 리소스 투입 순서만 조정한다.
* M4 단계의 플레이테스트 결과에 따라 M1~M3에서 확정한 밸런스 수치(balance_design_sheet.md)와 모드 설계(game_mode_info.md)를 다시 수정할 수 있다.
