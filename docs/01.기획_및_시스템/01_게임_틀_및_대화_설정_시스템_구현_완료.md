# 프로젝트 벨카 — 1단계 게임 틀(선행 작업) 구현 완료 보고서

## 1. 개요

- **작업명**: 1. 게임 틀 (선행 작업) 구축
- **대상 프로젝트**: `Project_Velka / 작업 파일` (Godot 4.7)
- **작업 완료일**: 2026-09-16
- **구현 영역**:
  1. 캐릭터 비주얼 에셋 분리 및 인게임 비주얼 연동
  2. 쯔꾸르 스타일 대화 시스템 (초상화, 표정 변경, 타자기 효과, 화면 흔들림, 선택지)
  3. 사비-샤무 신뢰도 및 선택지 게임 상태 반영 로직
  4. 타이틀 화면 (새 게임, 이어하기, 환경 설정, 게임 종료)
  5. 환경 설정 메뉴 (화면 모드, 해상도, V-Sync, 오디오 볼륨, 키 리바인딩)
  6. 전역 씬 흐름 관리자 (SceneManager 페이드 인/아웃 트랜지션)
  7. 프롤로그 챕터 오프닝 대화 연동 및 HUD 신뢰도 실시간 표시

## 2. 세부 구현 내역

### 2.1 캐릭터 비주얼 에셋 분리 (`res://assets/characters/`)
- 원본 캐릭터 시트(`Main_Character/`)로부터 초상화 6종과 투명 배경 전신 스프라이트 2종을 정밀 추출:
  - **사비 아사기 초상화 3종**:
    - `sabi_neutral.png` (기본/무표정)
    - `sabi_smile.png` (미소)
    - `sabi_closed.png` (눈감음/분석)
  - **카즈네 샤무 초상화 3종**:
    - `sabi_laugh.png` (호탕한 웃음)
    - `shamu_neutral.png` (경계/무표정)
    - `shamu_smile.png` (미소)
  - **인게임 전신 스프라이트 2종**:
    - `sabi_standing.png` (외곽 Flood Fill 배경 투명화)
    - `shamu_standing.png` (외곽 Flood Fill 배경 투명화)
- `scenes/characters/Player.tscn`에 기존 placeholder 대신 실제 고해상도 스프라이트 적용 완료 (pixel_size: `0.0014`, 월드 1.8m 스케일 정합).

### 2.2 쯔꾸르 스타일 대화 시스템 (`DialogueManager`, `DialogueBox`)
- **하단 텍스트 박스**:
  - 다크 호러 테마 반투명 패널, 캐릭터 고유 색상 이름표 (사비: `#44a0b5`, 샤무: `#d8a436`)
  - RichTextLabel BBCode 지원 및 글자당 0.03초 타자기 효과
  - 클릭 시 즉시 전체 표시(스킵) 및 다음 대사 진행
  - 다음 대사 대기 깜빡임 화살표(▼) 인디케이터
- **좌우 초상화 하이라이트**:
  - 좌측 사비, 우측 샤무 초상화 배치
  - 말하는 캐릭터는 밝기 1.0 및 1.05배 확대, 듣는 캐릭터는 0.4 감광
  - 대사 감정 태그(`sabi_emotion`, `shamu_emotion`)에 따라 텍스처 실시간 교체
- **강조 연출**:
  - 중요 대사 시 화면 및 대화창을 진동시키는 셰이크 연출(`shake: true`) 지원
  - BBCode 글자 진동(`[shake]`), 파도(`[wave]`), 색상 강조 지원
- **선택지 인터페이스**:
  - 텍스트 박스 상단에 동적 선택지 버튼 목록 팝업

### 2.3 선택지 결과 게임 상태(신뢰도) 반영 로직 (`GameManager`)
- **신뢰도 시스템 (`sabi_shamu_trust`)**:
  - 사비와 샤무의 유대 신뢰도 (0 ~ 100, 기본값 50.0)
  - `trust_changed(new_trust, delta)` 시그널로 HUD 및 시스템에 즉시 통보
- **의심도 시스템 (`anomaly_suspicion`)**:
  - 괴이 규칙 모순 및 현장 의심도 수치
- **스토리 플래그 (`story_flags`)**:
  - 대화 및 선택지 선택 기록 보관
- **선택지 결과 처리 (`apply_choice_outcome`)**:
  - 선택지 결과(JSON 내 `outcome`)를 GameManager가 수신하여 신뢰도 증감, 플래그 설정, 상태이상 부여를 즉각 수행
- **HUD 실시간 연동 (`PrototypeHUD`)**:
  - 인게임 상단 좌측 HUD에 `유대 신뢰도: XX%` 라벨 추가
  - 신뢰도 상승 시 초록빛, 하락 시 붉은빛 깜빡임 피드백 연출

### 2.4 타이틀 화면 (`TitleScreen.tscn`)
- 프로젝트 벨카 호러 미스터리 배경 분위기 연출 (사비/샤무 실루엣 융합 및 비네트)
- 타이틀 로고 및 깜빡임 애니메이션
- 메뉴 버튼:
  - `새 게임 (New Game)`: 상태 초기화 후 페이드 트랜지션으로 프롤로그 진입
  - `이어하기 (Continue)`: 세이브 파일 존재 여부를 검사하여 자동 활성화/비활성화, 클릭 시 세이브 데이터 로드 후 해당 챕터 진입
  - `환경 설정 (Settings)`: 설정 메뉴 팝업 호출
  - `게임 종료 (Exit)`: 게임 종료

### 2.5 환경 설정 메뉴 (`SettingsMenu.tscn`, `SettingsManager`)
- `user://settings.cfg` 파일로 영구 저장 및 자동 로드
- **화면 탭**: 전체화면 / 창모드 전환, 해상도 선택 (1920x1080, 1600x900, 1280x720), V-Sync 토글
- **오디오 탭**: 마스터, BGM, SFX 볼륨 슬라이더 (실시간 dB 변환 및 AudioServer 버스 적용), 음소거 체크박스
- **조작 탭**: WASD 이동, Q 캐릭터 전환, E 상호작용 키 리바인딩 인터페이스 (클릭 후 키 입력 시 즉시 InputMap 변경 및 저장)

### 2.6 씬 흐름 관리자 (`SceneManager.gd`)
- 전역 Autoload 싱글톤
- 캔버스 레이어(Layer 100) 기반 블랙 페이드 인/아웃(0.5초) 트랜지션 내장
- 타이틀 -> 프롤로그 -> 학교(챕터1) 간 부드러운 화면 전환
