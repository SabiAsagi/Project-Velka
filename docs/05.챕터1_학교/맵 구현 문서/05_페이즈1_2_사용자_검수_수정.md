# 페이즈 1·2 사용자 검수 수정

## 작업 범위

- 대상: 학교 맵 Phase 1 외곽 배치와 Phase 2 층 구조
- 기준: 12장 PNG의 형태·위치가 최우선이며, 확정 수치는 의미값으로 유지한다.
- 제외: 가구·소품·최종 재질·조명·NPC·내비게이션·Phase 3 실내 구현

## 공통 계단과 문 수정

- 본관 B1~4F의 좌측·중앙·우측 계단 앞에 임의로 놓였던 벽과 문을 제거했다.
- 별관 1F~3F의 양 끝 계단 앞을 막지 않도록 복도 경계벽을 끝 계단 구간에서 열었다.
- 본관 2F~4F의 교실 6개와 자습실 문을 각 방의 좌우에 정확히 한 쌍으로 배치했다.
- 문 위치는 별관 2F 제1과학실의 대칭 배치 방식을 기준으로 통일했다.
- 자습실처럼 문이 하나뿐이던 메인 방에는 반대쪽 문을 추가했다.

## 별관 수정

### 별관 1F

- 서측 학생 주출입구와 동측 비상·반입구 통로 앞을 막던 벽을 제거했다.
- 급식실 왼쪽 외곽벽을 추가했다.
- 조리 식품 창고 오른쪽 외곽벽을 추가했다.
- 급식실과 조리실 사이 내부 연결문을 추가했다.

### 별관 3F

- 도서관 중간 출입문 2개를 제거했다.
- 도서관 양 끝 출입문과 그룹학습실 출입문만 유지했다.

## 강당 1F 재구축

- 중앙 무대를 복구하고, 소품·의상 준비실과 음향·조명·무대장치실 사이에 맞게 폭을 재설정했다.
- 무대 계단 2개를 무대 구역 안쪽에 배치해 외곽으로 돌출되지 않도록 했다.
- 소품·의상 준비실, 무대, 무대장치실의 마룻바닥 방향 벽을 복구했다.
- 체육기구 창고, 북측 주출입홀, 행사물품 창고, 관리실의 마룻바닥 방향 벽을 복구했다.
- 관리실 중앙의 불필요한 벽을 제거했다.
- 내부 계단과 북측 주출입홀 사이를 막던 벽을 제거했다.
- 서측·동측 화장실 출입구를 추가했다.
- 북측 주출입구와 동·서측 출입구의 외벽 개구를 유지했다.

## 강당 2F 재구축

- 서측·북측·동측 ㄷ자 관람석과 중앙 개방부를 유지했다.
- 좌우 관람석을 전후 구간으로 나누어 참과 통로를 확보했다.
- 서측·동측 비상출입구를 강당 외벽 위치에 정렬했다.
- 외부 비상계단을 외벽 밖에 평행하게 배치하고, 각 출입구와 계단 사이에 연결 참을 추가했다.

## 전체 외곽 배치 재구축

- 최종 `00_전체_배치.png`의 부지 경계 픽셀을 190m × 140m 월드 경계에 등록했다.
- 본관, 별관, 강당, 운동장은 PNG에 그려진 외곽 사각형의 크기와 중심을 직접 반영했다.
- 본관 전면 도로, 별관 동측 도로와 상·하단 연결로, 운동장 남측·동측 도로를 추가했다.
- 본관 4개, 별관 2개, 강당 3개의 외부 문 위치 표식을 추가했다.
- 본관 뒤편 주차장, 후문, 자전거 거치대, 조회대·창고, 양 끝 계단, 농구장·관람 스탠드·화단·체력단련장을 유지했다.
- 본관 양옆에는 임의 보행로를 추가하지 않았다.
