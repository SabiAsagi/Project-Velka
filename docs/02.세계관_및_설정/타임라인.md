## 2. 아직 확정해야 할 항목

* 현재 시점의 정확한 연도
* 2000년 당시 사비와 샤무의 추정 연령
* 보육원 화재와 프로젝트 벨카 실험이 같은 사건인지, 서로 연동된 별도 사건인지
* 실험 기록의 `S`와 `C`가 사비와 샤무를 직접 가리키는지, 의도적으로 만든 오해인지
* 백윤서의 전이 시점과 협회 설립 후 경과 기간
* 현실세계에서 사비와 샤무에게 최초 의뢰를 건넨 정부 또는 비공식 기관의 정체
* 현실의 공식 기관이 괴이세계의 존재를 어느 수준까지 알고 있었는지
* 프로젝트 벨카가 두 사람의 전이를 의도적으로 유도했는지

## 3. 연표 작성 원칙

* `현대풍`만으로 충분한 구간에서는 정확한 연도를 화면에 노출하지 않아도 된다.
* 2000년 2월 8일은 우연한 반복이 아니라 메인 미스터리의 핵심 단서로 취급한다.
* 현실세계의 조사 기록과 괴이세계 내부의 협회 기록을 문서 디자인으로 구분한다.
* 본편 시작 이후의 챕터 이동은 새로운 전이가 아니라 괴이세계 내부 이동이다.
* 현실 귀환 성공 사례는 엔딩 또는 후속 설정에서 확정하기 전까지 만들지 않는다.
