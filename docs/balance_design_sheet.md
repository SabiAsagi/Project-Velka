# 밸런스 수치 설계 시트 (초안 프레임워크)

> 본 문서는 실제 최종 수치가 아니라, 밸런싱 논의를 시작하기 위한 뼈대와 플레이스홀더 값이다. 프로토타입 테스트 이후 반드시 조정된다.

## 1. 체력 / 공포 수치 기본값

| 항목 | 사비 아사기 | 카즈네 샤무 | 비고 |
| --- | --- | --- | --- |
| 기본 체력 | 100 | 120 | 샤무가 물리적으로 더 튼튼한 설정 반영 |
| 공포 수치 상승 속도 | 빠름 (기본치 x1.3) | 느림 (기본치 x0.8) | 사비 성격 반영 |
| 공포 수치 임계값 (시야/조작 페널티 발동) | 70% | 85% | |
| 유대감 링크 발동 조건 | 상대 체력 30% 이하 또는 공포 90% 이상 | 좌동 | 발동 시 상호 디버프 부여 |

## 2. 공포 수치에 따른 페널티 단계

| 구간 | 효과 |
| --- | --- |
| 0~40% | 페널티 없음 |
| 41~70% | 시야 약간 좁아짐, 이동속도 -5% |
| 71~90% | 화면 노이즈, 조작 반응속도 -15%, 선택지 일부 제한 |
| 91~100% | 심각한 시야 왜곡, 이동속도 -30%, 오조작 확률 발생 |

## 3. 자원 소모 기준값 (item_info.md 연동)

| 아이템 | 효과량 | 최대 소지 수량(기본 난이도) | 비고 |
| --- | --- | --- | --- |
| 구급상자 | 체력 50% 회복 | 2 | |
| 진통제 | 체력 15% 회복 + 붉은 노이즈 감소 | 3 | |
| 신경 안정제 | 공포 수치 -30 | 2 | |
| 손전등 배터리 | 손전등 지속시간 +5분 | 4 | 배터리 총 소모 속도는 맵별로 다르게 설정 |
| 조명탄 | 괴이 시선 분산 20초 | 2 | 샤무 전용 |

> 난이도별로 최대 소지 수량 및 드랍률을 -30%(고난이도) ~ +30%(쉬움) 범위에서 조정.

## 4. 챕터 난이도 곡선 (괴이 등급 기준 배치 가이드)

| 챕터 순서 | 주 등급 | 부 등급 | 미분류 등급 등장 |
| --- | --- | --- | --- |
| 1 (튜토리얼 성격) | 1~2등급 위주 | 최대 1개의 3등급 | 없음 |
| 2~3 | 2~3등급 위주 | 4등급 1개 (회피 전용, 조우 없이 존재만 암시) | 1개 |
| 4~6 | 3등급 위주 | 4등급 정면 조우 가능 | 2개 이상 |
| 후반 | 4등급 포함 복합 배치 | - | 다수 |

## 5. 협동 모드 vs 싱글 모드 난이도 보정

| 항목 | 싱글 모드 | 협동 모드 |
| --- | --- | --- |
| 괴이 감지 범위 | 기준치 | 기준치 x1.2 |
| 추격 지속시간 | 기준치 | 기준치 x1.15 |
| 자원 드랍량 | 기준치 | 기준치 x0.9 (2인이 나눠 쓰므로) |

## 6. 사망/실패 임계 조건 정리

| 원인 | 즉시형/누적형/지연형 | 비고 |
| --- | --- | --- |
| 괴이 포획 | 즉시형 | |
| 체력 소진 | 즉시형 | |
| 규칙 위반 - 안전/주의 등급 | 누적형 | 3회 누적 시 페널티 발동 |
| 규칙 위반 - 위험/금지 등급 | 즉시형~지연형 | 룰북 등급표 기준 |
| 제한시간 초과 | 즉시형 | 챕터별 개별 설정 필요 |
