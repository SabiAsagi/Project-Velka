# 사비 해킹 미니게임 및 프롤로그 시각 개선 — v0.27.0

## 1. 개요
기준은 main의 v0.26.0, 커밋 338fdb0ccc35848999f6a3c22e172a7a5402aa99이다.
의뢰인·협회 핵심 5명의 승인된 기본 초상화를 연결하고, CCTV와 도입부의 임시 그림을 일러스트로 교체한다.
사비·샤무의 가는 선과 셀 명암을 기준으로 사실적인 표면 질감을 줄였다. 주인공 원본 그림은 바꾸지 않았다.
작업본 버전이며 원격 main에 커밋하거나 올리지 않았다.

## 2. 플레이 경험
단말의 상태를 읽고 근거를 대조하는 사비의 능력을 조작으로 보여 준다.
실수는 무엇이 잘못됐는지 설명하고, 도움말과 관찰 힌트로 다시 판단할 수 있게 한다.
도움말을 읽는 동안에는 역추적이 멈춘다. 정답을 대신 입력하는 기능은 플레이어 화면에 제공하지 않는다.

## 3. 상세 규칙
- 공통: 남은 역추적 시간을 숫자로 표시한다. H 또는 버튼으로 현재 상태에 관한 힌트를 요청한다.
  F1 또는 버튼으로 도움말을 다시 열고, Enter/E/Esc로 닫는다. 도움말 중에는 조작과 역추적이 멈춘다.
  퍼즐 성공 후에는 종료 신호가 한 번만 발생하며, 완료 연출 도중 취소가 성공을 뒤집지 않는다.
- 회로: 좌클릭/Space/E/Enter로 시계 방향 회전, 우클릭/Q로 반대 회전. 방향키/WASD로 칸을 고른다.
  Z는 마지막 회전을 되돌린다. R은 이번 시도의 최초 배치로 되돌린다. 어느 쪽도 시간을 돌리거나 새 퍼즐을 뽑지 않는다.
  신호가 닿은 회로와 IN/OUT 연결 규칙은 기존과 같다.
- 암호: 중복 숫자, 범위 밖 숫자, 네 자리보다 적은 제출을 안내한다.
  잘못된 형식은 시도 횟수를 소모하지 않는다. Backspace는 한 자리, Delete/전체 지우기는 현재 입력만 지운다.
  기록에는 자리 일치 수와 숫자만 일치한 수를 함께 표시한다. 기록 기호는 시도 전체의 결과이며 특정 숫자의 정답 표시가 아니다.
  완성된 네 자리를 다시 제출하면 기존처럼 시도 한 번을 사용한다.
- CCTV: 7장/7초 간격과 훼손된 시각 표시를 유지한다. 클릭 두 번 또는 방향키+Space/Enter로 두 장을 교환한다.
  선택 장면을 확대하고 문·가방·조명 상태를 대조한다. Z는 마지막 교환을 취소한다.
  확대 화면에서도 훼손된 시각을 복구해 보여 주지 않는다.
  인물은 이동·주머니 확인·메모 읽기·문패 확인·문을 향해 손 뻗기의 평범한 행동을 한다.
  카메라 응시, 작별 인사, 사라짐을 예상하는 표정은 없다.
  영상 복원 → 짧은 재생 → 대사/원본 저장 → 정전이라는 기존 진행을 유지한다.
- 초상화: client/baek/kwon/seo/yu/han의 neutral을 등록했다.
  NPC는 주인공의 표정 필드 대신 자신의 emotion 필드를 읽으며, 없는 표정은 neutral로 대체한다.
  1254×1254 투명 PNG 원본과 작은 대화창용 사본을 함께 제공한다.
- 도입: 서로 다른 요일·장소의 실종을 유지한다. 장부 회수 장면의 사무실 소품을 보강했다.
  화면 효과 줄이기를 켜면 도입부의 장식적인 깜빡임·흔들림·이동 효과를 줄인다.

## 4. 계산과 상태
- 역추적 진행률 = 1 - 남은 시간 / 최초 제한 시간. 도움말 중에는 남은 시간을 차감하지 않는다.
- 회로의 시계 방향 회전은 기존 4비트 연결 마스크를 사용한다. 반대 회전은 같은 회전 연산 세 번이다.
- 암호 판정은 자리까지 일치하는 숫자 수와, 포함되지만 자리가 다른 숫자 수의 쌍이다.
- CCTV 실제 시각 = 17:41:00 + 실제 순서 인덱스 × 7초. 손상 여부는 기존 CORRUPTED 표를 따른다.
- 되돌리기는 배열 스냅샷을 복원한다. 시각, 역추적, 외부 단말 플래그를 바꾸지 않는다.

## 5. 경계 상황
성공/종료 후 입력을 차단한다. 취소와 성공의 외부 finished(bool) 계약은 유지한다.
도움말 중 키보드·마우스 입력이 퍼즐까지 전달되지 않게 한다.
되돌릴 기록이 없으면 현재 상태를 유지한다. 확대된 CCTV의 표시 훼손은 원본과 같다.
공장 경보·경비원 반응, 샤무에게서 사비로 조작을 넘기는 흐름은 기존 구현을 사용한다.

## 6. 의존성 및 구성
기존 HackBase / HackTerminal / DialogueBox / GameManager / DialogueManager / SettingsManager / VelkaStyle / SfxBank를 사용한다.
VelkaCinematicArt는 도입부와 CCTV에서 같은 일러스트 에셋을 읽는다. 실행 중 원격 이미지나 생성 API에 접속하지 않는다.
에셋은 assets/characters/portraits, assets/characters/cctv, assets/cinematics 아래의 로컬 PNG다.
아틀라스는 엔진에서 필요한 구역을 그리므로 원본 파일을 잘라 다시 저장하지 않는다.

## 7. 조정 항목
문/패널 회로, 보안 암호, 서버 영상의 기존 제한 시간·시도 횟수·난이도를 유지했다.
단말별 조정은 HackTerminal의 기존 속성과 PUZZLES 설정을 사용한다.
화면 배치와 글꼴·색은 기존 VelkaStyle 및 각 화면의 크기 상수를 따른다.
인물 아틀라스 3×3, 배경 2×2의 셀 순서와 경로는 VelkaCinematicArt에 명시되어 있다.
