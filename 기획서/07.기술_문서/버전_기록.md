# 프로젝트 벨카 — 버전 기록

## 버전 규칙

- 형식: `0.N.P` (프롤로그 개발판)
  - **N (가운데)**: 기능 업데이트마다 1씩 올린다. 새 장면, 새 시스템, 진행 방식 변경 같은 것이다.
    - 예: `0.19.0` → `0.20.0`
  - **P (마지막)**: 같은 버전 안의 버그 수정·자잘한 수정이면 1씩 올린다.
    - 예: `0.19.0` → `0.19.1` → `0.19.2`
  - 정식 챕터 체험판을 만들 때 `1.0.0` 으로 올린다.
- 지금까지(0.12 ~ 0.19)는 PR 번호와 가운데 숫자가 같았다. 앞으로는 PR 번호와 따로 가며, 기록에 PR 번호를 함께 적는다.
- 버전은 `project.godot` 의 `application/config/version` 한 곳에만 적는다.
  - 타이틀 화면 왼쪽 아래와 일시정지 메뉴에 `v0.19.0` 처럼 보인다.
  - 세이브 파일(`user://savegame.json`)에도 `version` 으로 남는다.
- main 에 합칠 때 버전을 올리고, 이 문서 맨 위에 한 줄 요약을 추가한다.

## 기록

### v0.21.0 — 컷씬과 플레이 섞기, 개체 교전 연출
- 컷씬 도구를 넣었다: 화면 위아래 검은 띠, 카메라 대상 바꾸기, 캐릭터가 스스로 걷기, 느린 화면·흔들림·번쩍임.
- 아지트: 보드를 풀면 샤무가 한숨 쉬고 혼자 1층으로 내려간다. 조작이 돌아오면 사비로 따라간다 (샤무로 바꿔 가방을 챙기던 단계는 없앴다).
- 공장: 사비 합류 때 자막 대신 사비가 어둠 속에서 걸어 들어온다.
- 공장 P-06 개체 교전
  - 조우: 개체가 어둠 속에서 서서히 드러나 어긋난 걸음으로 다가오고, 사비는 뒤로 물러서고 샤무가 나선다.
  - 교전: 칠 때마다 멈칫·흔들림·둔탁한 소리, 개체가 밀려났다가 뒤틀리며 되돌아온다.
  - 사비 부상: 순간이동 대신, 개체가 샤무 등 뒤로 파고드는 순간 느려지고 사비가 달려들어 대신 맞는다.
  - 압도: 카메라가 물러나며 개체가 하나둘 드러나고, 달려드는 순간 암전.
  - 개체 실루엣이 어둠 속에서도 보이게 했다.

### v0.20.0 — 달리기 숨·발소리
- 달리면 숨(스태미나)이 줄고, 바닥나면 숨이 찰 때까지 달릴 수 없다. 사비 80, 샤무 120.
- 캐릭터 카드에 '숨' 게이지를 넣었다. 바닥나면 "숨이 차다".
- 걸을 때·달릴 때 발소리가 난다. 달리는 발소리는 반경 7m 안의 경비원·괴이가 듣고 확인하러 온다.
- 숨이 바닥나면 헐떡이는 소리가 난다.

### v0.19.1 — 버그 수정·중계기 제거
- 중계기 원격 해킹을 뺐다. 샤무가 경비를 모두 재우면 사비가 들어와 단말을 직접 해킹한다.
  - 단독 잠입 중 목표는 "경비원을 들키지 않고 모두 제압하자 (n명 남음)" 하나다.
  - 단독 중 사비의 대화는 모두 무전으로 나온다.
- 공장 잠입 중 경비원에게 들켜 다시 시작하면, 사비가 마당에 멈춘 채 조작 대상이 되어 혼자 이상하게 움직이던 문제를 고쳤다.
  - 잠입을 시작하면 옆문 안쪽을 체크포인트로 저장한다. 들키면 샤무 혼자 거기서 다시 시작한다.
  - 사비가 합류할 때도 체크포인트를 저장한다. 재시작 뒤 경비가 이미 모두 쓰러져 있으면 바로 합류한다.
  - 단독 모드가 풀릴 때 두 사람 모두 다시 움직일 수 있게 했다.

### v0.19.0 — 공장: 샤무 단독 잠입 + 사비 무전 (PR #19)
- 사비는 마당에 남아 무전으로 돕고, 샤무 혼자 잠입한다.
  - 공장 안 단말(보안실·경보 장치)은 샤무가 중계기를 꽂으면 사비가 원격으로 해킹한다 (v0.19.1 에서 뺐다).
  - 지하 서버는 외부 망과 끊겨 있어 사비가 직접 와야 한다.
- 샤무가 들키지 않고 경비원을 **모두** 제압하면 사비가 합류한다.
- 무전 표시
  - 중요한 무전은 대화창에 `· 무전` 표시, 잡음, 푸르스름한 초상화로 나온다.
  - 짧은 힌트·경고는 왼쪽 아래 흐르는 자막으로 나오고 게임은 멈추지 않는다.
- 들키면 곧바로 '발각' 게임오버. 대화 중에는 경비원이 멈춰 선다.
- 샤무가 옆문·봉쇄문을 강제로 뜯을 수 있다. 사이렌이 울리고 경비가 2명씩 늘어난다.
- 샤무 제압은 눈치채지 못한 경비원의 등 뒤에서만 된다. 정면에서 치면 "막았다!".
- 보안실 단말 앞 의자가 조사를 막던 문제를 고쳤다.
- 폐쇄된 공장을 더 어둡게 했다: 경비원의 시야는 손전등이 전부다.
- 게임 버전 표시(타이틀·일시정지)와 이 버전 기록을 추가했다.
