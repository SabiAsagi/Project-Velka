> 확정되지 않은 연도나 인과관계는 임의로 채우지 않고 `미확정`으로 남긴다.

## 2. 아직 확정해야 할 항목

* 현재 시점의 정확한 연도
* 2000년 당시 사비와 샤무의 추정 연령
* 보육원 화재와 프로젝트 벨카 실험이 같은 사건인지, 서로 연동된 별도 사건인지
* 실험 기록의 `S`와 `C`가 사비와 샤무를 직접 가리키는지, 의도적으로 만든 오해인지
* 백윤서의 전이 시점과 협회 설립 후 경과 기간
* 현실세계에서 사비와 샤무에게 최초 의뢰를 건넨 정부 또는 비공식 기관의 정체
* 현실의 공식 기관이 괴이세계의 존재를 어느 수준까지 알고 있었는지
* 프로젝트 벨카가 두 사람의 전이를 의도적으로 유도했는지
* 두 사람이 프로젝트 벨카에서 맡았던 역할 (피험체 · 열쇠 · 기록 대상 등) — 버려진 날이 프로젝트의 일부라는 것만 확정
* "버려진 날 = 프로젝트의 일부"를 플레이어에게 밝히는 챕터와 방식

## 3. 연표 작성 원칙

* `현대풍`만으로 충분한 구간에서는 정확한 연도를 화면에 노출하지 않아도 된다.
* 2000년 2월 8일은 우연한 반복이 아니라 메인 미스터리의 핵심 단서로 취급한다.
* 현실세계의 조사 기록과 괴이세계 내부의 협회 기록을 문서 디자인으로 구분한다.
* 본편 시작 이후의 챕터 이동은 새로운 전이가 아니라 괴이세계 내부 이동이다.
* 현실 귀환 성공 사례는 엔딩 또는 후속 설정에서 확정하기 전까지 만들지 않는다.
* **"프로젝트 벨카"라는 이름은 세계 안에서 숨겨진 실험의 이름이다.** 게임 밖 화면(타이틀 · 로딩 · 저장 · 게임 오버 · 제작진)의 PROJECT VELKA 는 게임 제목이라 늘 보이지만,
  세계 안 화면(조사 기록 수첩 · 해킹 단말 · 사건 보드)의 머리말에는 진상이 드러나기 전까지 나오지 않는다.
  * 평소: 수첩 "괴이저항단체 / FIELD RECORD", 해킹 "SABI // ACCESS INTERFACE", 사건 보드 "SABI / INVESTIGATION"
  * 프로젝트 벨카 시설의 단말(연구소 등, `HackTerminal.project_terminal`)에서는 해킹 머리말에 "PROJECT VELKA / ACCESS INTERFACE"가 붉게 뜬다 — 게임 제목이 세계 안에 처음 나타나는 반전
  * 진상 공개 뒤(이야기 플래그 `project_velka_revealed`)에는 수첩 · 해킹 · 보드 머리말이 조용히 PROJECT VELKA 로 바뀐다 — "우리 기록도 처음부터 그 실험의 일부였다"
