## 2. 씬 분리

전체 맵을 한 씬 또는 한 번의 자동 생성 스크립트로 만들지 않았다. 다음과 같이 기능별 정적 씬으로 분리했다.

1. `scenes/school/SchoolMap.tscn`: 학교 맵 조립 루트
2. `scenes/school/exterior/Exterior.tscn`: 부지·운동장·동선·외부 고정 시설
3. `scenes/school/buildings/MainBuildingMass.tscn`: 본관 외형 매스와 외부 출입구
4. `scenes/school/buildings/AnnexBuildingMass.tscn`: 별관 외형 매스와 외부 출입구
5. `scenes/school/buildings/GymBuildingMass.tscn`: 강당 외형 매스와 외부 출입구
6. `scenes/school/connections/MainAnnexSkybridge.tscn`: 본관 2F↔별관 3F 구름다리 외형
7. `scenes/school/debug/DebugTools.tscn`: 정본 오버레이·앵커·상단 카메라

`SchoolMap` 루트에는 `Exterior`, `MainBuilding`, `Annex`, `Gym`, `Connections`, `Gameplay`, `Navigation`, `Debug`를 분리해 두었다. `Gameplay`와 `Navigation`은 다음 승인 단계용 빈 루트이며 Phase 1에서 기능을 추가하지 않았다.

## 4. 외부 고정 시설

다음 시설을 최종 전체 배치도 위치와 방향대로 구현했다.

- 북측 본관 뒤편 주차장, 후문 진입로, 자전거 거치대
- 본관 전면 정원 띠, 연속 3m 보행로, 스탠드
- 스탠드 양끝 계단, 중앙 조회대, 운동장 방향 하부 창고문
- 운동장 동측 3m 보행로와 본관 대지 연결 경사로
- 서측 별관과 막다른 길이 없는 휴식 정원 순환 산책로
- 동측 정문, 진입광장, 수위실, 정원, 원예부 재배화단
- 강당 양옆 농구장, 각 농구장 남측 관람 스탠드와 화단·수목 매스
- 농구장 외곽의 서·동 체력단련장과 남측 연속 보행로
- 북측·서측 산림 및 경사 지형의 Phase 1 평탄 매스

본관 양옆 임의 길, 스탠드 중앙 계단, 별관 중앙 계단, 강당 남측 출입구는 만들지 않았다.

## 5. 외부 출입구와 연결

### 본관

- 남측 전면 서쪽 출입구
- 남측 전면 중앙 현관
- 남측 전면 동쪽 출입구
- 북측 후문

### 별관

- 운동장을 향하는 동측 북단 출입구
- 운동장을 향하는 동측 남단 출입구

### 강당

- 북측 주출입구
- 서측 출입구
- 동측 출입구
- 남측 외부 출입구 없음

### 구름다리

본관 2F 서측에서 먼저 서쪽으로 나간 뒤 남쪽으로 꺾어 별관 3F 북단에 연결했다. 바닥 기준 경로는 `Y=7.6`이며 본관 2F를 별관 2F에 연결하지 않았다.

## 6. ReferenceOverlay

`Debug/ReferenceOverlay`는 다음 조건으로 남겼다.

- 정본 `00_전체_배치.png`만 사용
- 운동장 경계를 월드 기준 앵커로 사용
- 비교 투명도 `50%`
- 충돌 및 내비게이션 없음
- 편집 잠금 메타데이터 적용
- 기본 상태 `visible=false`
- 전체 경계와 운동장·본관·별관·강당·정문 앵커 포함
- `DebugTopCamera` 포함
